# Responsible security research

This repository documents adversarial robustness research. Evaluate only models, datasets and environments that you own or are explicitly authorized to test. Do not use results to compromise third-party applications, services or deployed safety-critical systems.

For a possible security issue affecting this repository, avoid posting sensitive details, credentials or personal data in a public issue. If GitHub private vulnerability reporting is available, use the repository's Security tab; otherwise open a minimal issue requesting a private communication channel. For issues affecting third-party software, follow its maintainers' disclosure policy.

When reporting a repository issue, provide the affected commit, environment, impact, and a minimal non-sensitive reproduction. No response-time or fix-time guarantee is currently established.
